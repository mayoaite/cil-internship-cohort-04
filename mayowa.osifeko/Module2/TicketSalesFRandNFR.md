# Ticket Sales System Requirements
## Functional
-	Users must be able to browse for events by name or date or venue. **BUSINESS**
-	Searching for events by keywords should also be possible. **USER**
-	User will select ticket price from those offered and also specify the number of tickets they require. **USER**
-	Ad hoc reporting will be required, showing ticket sales over a week. It should be possible to vary that time span and look at any duration up to six months. **ADMINISTRATIVE**
-	It should not be possible to double-book tickets (i.e. buy a ticket that has already been sold). **BUSINESS**
-	Daily reports of ticket sales must be generated. These must be retained for two years. **ADMINISTRATIVE**
## Non-functional
-	The system should display availability of the tickets within five seconds. **PERFORMANCE**
-	All data is to be backed up nightly. **RELIABILITY**
-	Users must be able to choose their seats and purchase tickets 24/7. **AVAILABILITY**
-	Only registered customers can buy tickets. **ACCESSABILITY/SECURITY**
